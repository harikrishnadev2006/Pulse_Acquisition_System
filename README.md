# Digital Pulse Acquisition and Analysis System

STM32-based pulse acquisition system using external interrupts, timers, OLED display, and UART logging.

## Hardware

- STM32F103C6T6 Blue Pill
- LM393 Comparator
- SSD1306 OLED
- CH340 USB-UART

## Features

- Pulse counting
- CPS calculation
- Pulse interval measurement
- OLED display
- UART logging

## Repository Structure

Core/ -> Application source code

Drivers/ -> STM32 HAL drivers

project.ioc -> CubeMX configuration
